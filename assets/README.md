## App icon
`copy.svg` contains the yellow clipboard-and-sparkle artwork used by the toolbar.
`icon-16.png`, `icon-32.png`, `icon-48.png`, and `icon-128.png` are transparent
PNG exports for Chrome. `copy.png` is a matching compatibility export.

## Inter typography
`inter-var.woff2` is bundled locally so the toolbar and settings do not require a
remote font request.
